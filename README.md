# I210
Coursework for INFO-I210 at IU (Python fundamentals)

code_like_2: Student directory for Luddy School departments. Stores students and their department codes in dictionaries, lets you add a student, shows the total count and first/last names alphabetically, and looks up which department a student is in.

code_like_3: Conference check-in. Prints the attendee list, then checks whether a name is an attendee, a speaker, or not registered, with an option to add them.

code_like_4: Meeting RSVP tracker. Lets you add or remove guests in a loop, records whether each is vegetarian, then prints a summary of total guests split by meal preference.

code_like_5: Card dealer. Builds and shuffles a 52-card deck, asks for 1–5 players, and deals each player a 5-card hand.
